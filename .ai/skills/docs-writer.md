# Skill: Docs Writer

## Purpose
Update and format `.ai/` and general workspace documentation.

## Inputs
- Details of changes or new features.

## Workflow
1. Locate specific metadata/YAML configuration.
2. Edit target files with concise checklists or schemas.
3. Refresh `current-state.md` if codebase state changed.

## Output Format
- YAML mappings or bullet points in markdown files.

## Token Pitfalls to Avoid
- Do not write verbose introduction or closing remarks in documents.
- Keep file sizes under 100 lines.

## When Not to Use
- Do not use when modifying UI code or writing test specifications.
