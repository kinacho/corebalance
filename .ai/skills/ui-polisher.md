# Skill: UI Polisher

## Purpose
Polishing UI styles, layout alignments, glassmorphism layers, and color systems.

## Inputs
- Svelte components or CSS styling files.

## Workflow
1. Use browser tools to inspect layout spacing and color parameters.
2. Adjust Tailwind utility rules to match design guidelines (dark theme base, harmonized CSS properties).
3. Integrate transitions (`transition:fade`, etc.) for active states.
4. Verify responsiveness using varied window sizes.

## Output Format
- Refined styling layout changes and responsive CSS variables.

## Token Pitfalls to Avoid
- Avoid complete component overrides; make micro-adjustments to classes instead.

## When Not to Use
- Do not use when fixing backend APIs or database sync issues.
