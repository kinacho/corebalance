# Skill: SvelteKit Implementer

## Purpose
Build or update components, pages, layout configurations, and SSR endpoints.

## Inputs
- Route specs or component details.

## Workflow
1. Check Svelte 5 rune layout standard.
2. Edit target component or server-side router.
3. Validate routing hooks and reactive values.
4. Execute `npm run check` to verify TypeScript compliance.

## Output Format
- Clean, reactive Svelte 5 components or TS backend routes.

## Token Pitfalls to Avoid
- Avoid copying full layout files when modifying single divs.
- Do not import Svelte components dynamically unless optimizing load speed.

## When Not to Use
- Do not use for testing workflows or updating Firestore database configurations.
