# Frontend Rules

- **Tailwind CSS v4**: Follow utility structure. The config resides in Vite plugin `@tailwindcss/vite` instead of a tailwind.config.js file.
- **Aesthetic Quality**: Build with a dark mode base theme (`#0a0a16`), glassmorphism effects, harmonized CSS variables, and modern font choices (Inter/Roboto).
- **Responsive design**: Target mobile-first. Ensure sitemaps, menus, and charts adjust to smaller device layouts correctly.
- **Charts (Chart.js)**: Maintain responsive canvas elements and customized tooltips for portfolio data display.
