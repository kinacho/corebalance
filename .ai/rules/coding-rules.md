# Coding Rules

- **Minimal Diffs**: Target exact lines of code. Do not rewrite files just to change layout, indentation, or comments.
- **Local Reasoning**: Understand the current file before looking elsewhere. Avoid importing dependencies unnecessarily.
- **TypeScript Strictness**: Adhere to existing typings. Ensure interfaces are followed correctly.
- **No Leftover Debugging**: Remove all `console.log` statements and temporary test mocks before final submission.
- **Code Ownership**: Follow established formatting and variable naming rules of the active project.
