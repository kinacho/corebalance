# Documentation Rules

- **Anti-Bloat**: Never write long narratives, history, or non-actionable background info.
- **English Only**: Keep operational guides, rules, and notes in English to minimize token consumption.
- **No Redundancy**: Do not duplicate stack configurations or schemas across multiple documents. Keep a single source of truth in context files.
- **YAML Preferred**: Use YAML/JSON for structures, lists, and checklists to make documentation easy for machines to scan.
