# Global Rules

- **Git Limit**: NEVER perform any Git operations (commit, checkout, branch, rebase, push, pull, stash, add) without explicit, prior authorization from the user.
- **Scope Restriction**: Keep all changes minimal and targeted. Do not rewrite unrelated components or make speculative improvements.
- **Language**: Use English for all operational, logging, and code-instruction steps.
- **Windows Preference**: Default to Windows-safe console syntax and tooling.
- **Preserve Behavior**: Never break existing features unless the task explicitly requires it. Favor backwards-compatible adjustments.
