# Glossary

- **Rebalance**: Adjusting the weights of assets in a portfolio to match original targets.
- **ISIN (International Securities Identification Number)**: Standard code uniquely identifying securities.
- **Ticker**: Short code representing a stock or fund (e.g., IWDA.AS).
- **TER (Total Expense Ratio)**: Annual fee charged by a fund to cover management costs.
- **Core / Satellite / Stocks**: Asset classifications where "Core" represents passive index ETFs (90%), and "Satellite" / "Stocks" form tactical bets (5% / 5%).
- **Ledger**: The transaction log (buys, sells, dividends) that forms the source of truth for holdings.
- **FX Rate**: Foreign exchange rate used to convert asset values into the base currency (EUR).
