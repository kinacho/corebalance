# CoreBalance Product Scope

## Core User Flows
1. **Onboarding**: No-signup access. System sets a default portfolio (e.g., 90/5/5 allocation).
2. **Import / Setup**: Manual transaction inputs or CSV uploads of portfolio data.
3. **Dashboard View**: Real-time asset weights, performance analytics, and cost ratios (TER).
4. **Rebalancing Workflow**: User inputs target allocations and new capital; the app calculates precise trade directives.
5. **Crisis Simulation**: Drag-and-drop or select major historical market crashes (2008, 2000, 2020) to see simulated drawdown effects.

## Out of Scope
- Direct trading or broker integration (read-only calculation tool).
- Institutional/Corporate accounting.
- Multi-user sharing, multi-portfolio sync management or tenant segregation.
- Complex tax-loss harvesting advice.
- Real-time stock alerts.
