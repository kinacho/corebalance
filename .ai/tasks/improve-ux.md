# Improve UX Template

## Goal
Optimize visual representation, responsive layouts, theme styling, or micro-animations.

## Required Inputs
- Target page, layout, or component.
- UX enhancement brief.

## Allowed Context Sources
- `layout.css`, Svelte component logic, `src/lib/components/`.

## Steps
1. Inspect design variables, glassmorphism layers, and responsive break points.
2. Edit Tailwind CSS v4 directives or custom CSS in components.
3. Incorporate micro-animations/transitions (e.g. svelte/transition).
4. Verify layout is mobile-first, matching PWA display modes.

## Deliverables
- Polished, responsive component design.

## Stop Conditions
- Visual standards met on both desktop and mobile viewports.

## Token-Saving Notes
- Keep visual adjustments modular to prevent layout breakages.
